# Asset Manager User Admin

This is a local admin page for creating Firebase Authentication users and approving them for Asset Manager.

## First-time setup

1. Open Firebase Console.
2. Open project `assetmanager-f2ac7`.
3. Go to Project settings > Service accounts.
4. Click Generate new private key.
5. Run:
   `npm install`
6. Run:
   `npm start`
7. Open:
   `http://127.0.0.1:5055`
8. Paste the downloaded JSON into the setup box.

The private key must stay on the admin computer. Do not put it in the public Asset Manager app.
